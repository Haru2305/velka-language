## 19. 圧力メモ
今回も新しい不透明L0語根は導入しない。

反復して安定した資源:
- `go bal` 「大丈夫／気にしないで」
- `pit`, `pit=rek` 程度・量の弱化
- `yo`, `pe`, `hai` 推量・可能性・判断保留
- `ren`, `tarka`, `tar`, `renren` 短答
- `balka`, `lumi` 小さな摩擦の修復
- `gera` 同意を保ちながら留保を置く
- `weir` 「あとで」。予定調整では具体時刻を追加する圧力が強い

統合担当への観察:
1. 「充電する」は透明表現で処理したが、日常頻度に対して迂言的。既存電力語彙を再監査する価値がある。
2. 「任せる」は `ta jem` で短く処理でき、専用L0追加は不要。
3. 「急がなくていい」は `go kuri` が日常的に使える。禁止命令との語用論境界を継続監査。
4. 「今すぐ返答不要」は `kiri zel go balir` がメッセージ場面で有用。
5. 「結論はいらない、聞いてほしい」は `jem dar go; se=rek mipa` が機能し、例文帳候補。
