## 圧力所見
- 物理的な別れの後味は fel / we / mun / ora と、送らない・見ない行為で十分描写できる
- 他者の幸福を祝う感情と自分の felmi は同時に成立し、専用の「複雑な嫉妬」語を急いで立てる必要はない
- 世代継承は harrem と共同作業、速度差、身体描写で自然に表現できる
- 雨上がりの静けさは ran + kel と環境音の減少で描け、専用気象語は不要
- 離れた場所で同じ行為をする親密さは ben を明示せず、同一対象と短い通信の反復でも表現できる
- 記憶媒体を消せない葛藤は ker / vas / sek / benmi / balmi / felmi の組合せで表現可能
- 和解は ren を明示しなくても共同の食事・物品授受・翌日の予定で語用論的に示せる
- 季節外れの衣服は har を時間だけでなく「現在の環境に対して古い／残存する」意味へ拡張する圧力がある
- 電話越しの沈黙は ora を「無内容」ではなく共有された談話状態として使う例を増やせる
- 新規L0昇格なし。比較・嫉妬系の専用語は引き続き保留する
