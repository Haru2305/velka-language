## 圧力所見
- 停電は dum / bel / fal / tam / ora で描写でき、専用L0は不要
- 祝福後の孤独は belmi → felmi の時間推移で自然
- 待合の不安は dummi を直接多用せず、待機・反復質問・短答で表現可能
- sen と har を同一対象へ重ね、話者ごとの時間感覚を対照できる
- 古い録音は har + survas + se で足り、媒体専用語は現時点で不要
- 帰郷後の違和感は fal だけでは粗く、ben / wen / har / sen の組合せが有効
- 親友への比較由来の嫉妬・劣等感は既存感情語だけだと迂言が長く、継続監査価値が高い
- matam は共同作業場面で自然に機能
- 新規L0昇格なし
