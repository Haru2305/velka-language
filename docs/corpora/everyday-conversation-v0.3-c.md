## 34. 圧力メモ
今回も新しい不透明L0語根は導入しなかった。

反復して安定した資源:
- `ren / tarka / tar / renren`：短答、了解、受容
- `pit / pit=rek`：程度の弱化
- `yo / hai`：推量と判断保留
- `go bal`：謝罪受容・「気にしないで」
- `balka / lumi`：小さな摩擦の修復
- `gera`：同意を維持したまま留保
- `kerka`：予定・場所・数量の再確認
- `ke=men?`：広すぎる問いを具体化する会話修復
- `se=rek`：「聞くだけ」を短く示す相談前のメタ会話
- `go kuri`：「急がなくていい」。命令の否定より対人的配慮として反復

統合担当への候補:
1. 「充電する」は専用L0を追加せず、既存の電気・接続語彙を利用する方針を継続。本稿では `elekbenmak` と `ben` で処理した。
2. 「傘」は既存正本辞書に正式形がある場合、それを優先し、旧コーパスの試験的透明複合を増殖させない。
3. 「相談前に欲しい反応を指定する」`dar mipa da, se=rek?` は日常会話教材への収録価値が高い。
4. 「短い返信が冷たく見える」場面では、専用感情語を増やさず `gor` + 文脈説明で修復可能。
5. `kerka` は待ち合わせ、数量、役割分担で繰り返し有効。口語の確認標識として統合側で用法整理する価値がある。
6. 褒めを受ける場面で `lumi` の後に自己否定せず評価を受け取る構文が自然に成立する。
