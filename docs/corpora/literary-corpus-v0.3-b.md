## 圧力所見
- 喪失は mermi を直接述べなくても物の配置・習慣の残存・人数との不一致で表現可能
- 再会は har、距離、視線、手の移動の組合せで専用語なしに描ける
- pirmi / belmi / balmi / benmi の併存は自然で、複合感情を単一ラベルへ強制する必要は薄い
- 嫉妬は現体系では迂言がやや長い。複数コーパスで再発するか継続監査する
- ora と行動描写の組合せが沈黙の描写で有効
- pit / mag は物理量だけでなく感情強度・会話量・回復度へ拡張できる可能性が高い
- 新規L0昇格なし。「嫉妬」「ためらい」は継続観察
