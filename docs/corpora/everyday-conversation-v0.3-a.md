## 25. 会話圧力メモ

この追加では、新しい不透明L0語根を導入しなかった。

反復して安定した既存資源:
- `Ren.` / `Na.` / `Tar.` / `Tarka.` / `Renren.` の短答
- `Pit.` / `Pit=rek.` による量・程度の弱化
- `Yo.` / `Hai.` による確度・判断保留
- `Go bal.` による「気にしないで／大丈夫」
- `Balka.` / `Lumi.` による謝罪・感謝
- `Gera` で対立・ためらいを自然につなぐ
- 親密な相手への `reta`
- 回復可能な主語・目的語の強い省略
- チャットでは証拠性・主語がさらに省略されやすい

統合担当への候補:
1. 「傘」は本コーパスで透明複合 `ranmak`（雨＋道具）として使用。日常で高頻度だが、現時点では独立L0化せず透明複合のまま圧力試験を続ける。
2. 「投稿する／SNSに載せる」は `neti=te ba`（ネットへ与える）で処理可能。専用L0は不要。
3. 「鍵をかける」は `gurkel kel` の既存資源で表現できるが、会話頻度が高いため今後も迂言性を監査する。
4. 「おやすみ」は本稿では `dumsol reni` を透明な定型句として試用。複数コーパスで定着するか確認する。
5. 照れは既存 `jemmi`、心配は `rekmi`、苛立ちは `pirmi` で十分に表現でき、新規感情語根は不要だった。
