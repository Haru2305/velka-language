# Velka語 日常例文帳 v0.1

> 普段使い・会話・文学の両方で使い回せる短文を集める。今後のコーパスから自然な例文を継続追加する。

## 1. 挨拶

```text
Renka.
やあ／こんにちは

Munka.
またね／さようなら

Lumi.
ありがとう

Lumi=re.
ありがとうございます

Balka.
ごめん

Balka=re.
申し訳ありません
```

## 2. 今・あとで・予定

```text
Kir ma go we-e.
今は行かない

Weir ma we-e=mi.
あとで行くつもり

Ta jisol ji-e da?
明日来る？

Ma jisol ji-e=mi.
明日行くつもり
```

## 3. 食事

```text
Ma rinmi=m.
お腹がすいた

Ma sumi=m.
喉が渇いた

Rinsam rin-e da?
ご飯食べる？

Ma kofi su mipa=m.
コーヒー飲みたい

Ma rinsam pirmak-e=mi.
ご飯を作るつもり
```

## 4. 疲労・休憩


## 17. 学習メモ

日常会話では、完全な文よりも

- 主語省略
- 短答
- 証拠性フレームの継続
- 文脈依存
- 相づち
- 既知情報の省略

が多い。

今後は実際の文学・日常コーパスから、口語短縮や会話らしい崩れを継続的に抽出して追加する。
