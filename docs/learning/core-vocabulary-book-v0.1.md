# Velka語 基本単語帳 v0.1

> 「911語を全部ばらばらに覚える」のではなく、語形成の核となる**162の独立暗記単位**を先に覚えるための単語帳。

## 使い方

- 表の左列だけを見て日本語を答える
- 逆向きにも確認する
- 固有語根128語 → 借用語31語 → 不透明機能語3語の順で覚える
- 複合語は構成要素へ分解して理解する
- 例：`datbenra = dat + ben + ra` のように、未知語でも語根から推測する

## E. 覚え方の原則

Velka語では、「単語を1個ずつ暗記する」より「語根を再利用する」ほうが効率がよい。

たとえば `ben` を覚えると、

- `benan` 仲間
- `benmak` 助ける
- `benmi` 好意・愛着
- `karben` 橋
- `datben` 関連

をまとめて理解できる。

この単語帳は今後、実際のコーパス頻度に基づく **頻度順デッキ**、**日常語デッキ**、**文学語デッキ**へ拡張する。
