# Velka語 学習文法書 v0.1

> 学習者向けの通読用文法書。規範の正本は `docs/grammar/` 以下。本書は正本を学びやすい順番へ再構成した教材である。

## 0. 最初に覚えること

Velka語の骨格はかなり単純である。

1. 基本語順は **SOV**
2. 主語・目的語は文脈で頻繁に省略する
3. 修飾語は原則として名詞の前
4. 動詞の後ろに「出来事の輪郭」を付けられる
5. 独立した事実断定では、原則として「どう知ったか」を示す
6. 格関係の多くは後置詞で表す
7. 新語は少数の語根を組み合わせて作る

最初の例：

```text
ma wa su-ke=n.
私 水 飲む-COMP=DIR
「私は水を飲んだ」
```

## 1. 基本語順

### 1.1 SOV

```text
ma vasmar tar=m.
私 本 理解する=INT
「私はその本を理解している」
```

### 1.2 省略

誰について話しているか明らかなら、主語や目的語は省略できる。

```text
rin-ke=n.
食べる-COMP=DIR
「食べた」
```

### 1.3 修飾

修飾語は原則として前に置く。

```text
bel dom
明るい 家

[ma na-ke=n] an
私 見る-COMP=DIR 人
「私が見た人」
```

## 2. 述語の形

基本形：

```text
語根 - 事態輪郭 = 証拠性 = 確度 = 丁寧
```

例：

```text
fal-ke=se=yo=re
壊れる-COMP=REP-PROB-POL
「壊れたと聞いており、おそらくそうだと思います」
```

全部を毎回付けるわけではない。

## 3. 事態輪郭

| 形 | 名称 | 中心意味 |
|---|---|---|
| 無標 | STAT | 状態 |
| `-e` | PROS | 成立前・予定・予期 |
| `-ne` | INCH | 開始 |
| `-ra` | DUR | 進行・継続 |
| `-ke` | COMP | 完結 |
| `-la` | RES | 結果状態 |
| `-se` | CESS | 終了 |
| `-ri` | HAB | 習慣・反復 |
| `-in` | GNOM | 一般命題・定義 |

### 3.1 例

```text
ma rin-e=mi.
「私は食べる予定だ」

ma rin-ra=n.
「私は食べている」

ma rin-ke=n.
「私は食べた」

ma kofi su-ri.
「私は習慣的にコーヒーを飲む」
```

Velka語に義務的な過去・現在・未来時制はない。時間副詞と事態輪郭で表す。

## 4. 証拠性 — 「どう知ったか」

| 形 | 名称 | 意味 |
|---|---|---|
| `=na / =n` | DIR | 直接知覚・直接確認 |
| `=mi / =m` | INT | 内的感覚・意図・思考 |
| `=ra / =r` | INF | 痕跡や事実から推論 |
| `=se / =s` | REP | 人から聞いた |
| `=lu / =l` | RCV | 記録・制度・文書から得た |
| `=ha / =a` | UNS | 情報源を確立しない |

### 4.1 比較

```text
wan ji-ke=n.
「彼が来たのを自分で確認した」

wan ji-ke=s.
「彼が来たと聞いた」

wan ji-ke=r.
「痕跡から彼が来たと推測する」

wan ji-ke=l.
「記録上、彼が来た」
```

同じ情報源が続く談話では、後続文の証拠性を省略できる。

## 5. 確度

| 形 | 意味 |
|---|---|
| `=di` | 強い確信 |
| `=yo` | かなりありそう |
| `=pe` | 可能性あり |
| `=hai` | 判断を閉じない |

証拠性と確度は別物。

```text
wan ji-ke=se=yo.
「来たと聞いた。たぶん本当だと思う」
```

## 6. 否定と疑問

### 6.1 否定 `go`

否定したい要素の直前。

```text
ma go we-e.
「私は行かない」

ma kofi go su.
「私はコーヒーを飲まない」
```

### 6.2 Yes/No疑問 `da`

```text
ta ji-e da?
「来る？」
```

### 6.3 疑問基体 `ke`

`ke` は「何・どれ」の基本形。

```text
ke an ji-ke da?
「誰が来た？」

keter ta we-e?
「どこへ行く？」
```

## 7. 後置詞

| 後置詞 | 中心意味 |
|---|---|
| `=ji` | 方向・受け手・相手・受益者 |
| `=do` | 到達点・終点 |
| `=fel` | 起点・出所 |
| `=te` | 場所 |
| `=ben` | 共同・同伴 |
| `=tam` | 手段・道具 |
| `=kar` | 経路・通過点 |
| `=men` | 関連・話題 |
| `=pa` | 所有・所属 |
| `=bor` | 内部 |
| `=hal` | 上方 |
| `=ter` | 下方 |
| `=rek` | 境・縁 |

### 7.1 例

```text
ma dom=fel tardom=do we-e=mi.
「私は家から学校へ行くつもりだ」

ma benan=ben cafa=te ara-ra=n.
「私は友人とカフェにいる」

ma ta=ji vasmar ba-ke=n.
「私はあなたに本を渡した」
```

## 8. 代名詞

基本：

- `ma` 私
- `ta` あなた
- `kian` 目の前にいる第三者
- `wan` その場にいない第三者
- `tewan` 談話ですでに出た第三者

関係性を表す二人称もある。

- `reta` 親密なあなた
- `balta` 責任関係のあなた
- `venta` 義務・債務関係のあなた
- `gorta` 対立関係のあなた
- `menta` 制度上の役割としてのあなた

## 9. 複文

### 9.1 内容補文 `ka`

```text
ma [wan ji-ke=n] ka ker=m.
「彼が来たのを覚えている」
```

### 9.2 条件 `da`

```text
ran ji-e da, ma dom=te ara-e.
「雨なら家にいる」
```

### 9.3 理由 `raka`

```text
ma nelmi=m raka, kir go we-e.
「疲れているので、今は行かない」
```

### 9.4 並列と対比

- `be` そして
- `gera` しかし・それに反して

```text
ma we-e, gera wan go we-e.
「私は行くが、彼は行かない」
```

## 10. 使役・許可・受動

### 10.1 使役 `V-mak`

```text
ma pitan=ji mor-mak-ke=n.
「私は子どもを寝かせた」
```

### 10.2 許可 `gur`

```text
ma pitan=ji fel gur-ke=n.
「私は子どもが外へ出るのを許した」
```

### 10.3 被影響態 `V-lu`

```text
ma wan=fel tor-lu-ke=n.
「私は彼に押された」
```

行為者は `=fel` で示せる。

## 11. 情報構造

### 11.1 話題 `=men`

```text
wan=men, ma pit tar.
「彼については少し分かる」
```

### 11.2 焦点 `=je`

```text
ma=je vasmar pa-ke=n.
「本を取ったのは私だ」
```

### 11.3 排他 `=rek`

```text
ma=rek we-e.
「私だけが行く」
```

### 11.4 添加 `=be`

「〜も」に相当する添加。

## 12. モダリティ

### 能力 `dori`

```text
ma kar dori=m.
「私は渡れる」
```

### 必要 `balir`

```text
wa su balir.
「水を飲む必要がある」
```

### 欲求 `mipa`

```text
ma nau na mipa=m.
「船を見たい」
```

能力・可能性・許可・必要・義務・責任・欲求・意図は意図的に別概念として扱う。

## 13. 丁寧さ

文末の `=re` は、上下関係そのものより「相手の判断余地を残し、角を落とす」丁寧標識。

```text
lumi=re.
「ありがとうございます」

balka=re.
「申し訳ありません」

vasmar ba dar=re.
「本を渡していただけますか」
```

## 14. 語形成

Velka語は、語根を大量に増やすより既存要素の再利用を重視する。

優先順位：

1. 既存語の意味拡張
2. 透明な複合
3. 生産的派生
4. 語彙化した古い複合
5. 借用
6. 計画的新語

### 14.1 右側主要部

```text
kar + ben → karben 「橋」
tar + dom → tardom 「学校」
ven + kas → venkas 「価格」
```

### 14.2 人物 `-an`

```text
mak + an → makan 「職人」
ven + an → venan 「商人」
```

一回その行為をしただけの人には普通使わない。

### 14.3 状態 `-i`

```text
bal → bali 「重い」
wa → wai 「濡れている」
```
