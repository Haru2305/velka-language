# Velka語体系プロジェクト 正本 v2.1


### 位置づけ
この文書は本プロジェクト全体の現行正本
祖語から現代標準語までの歴史、音韻、文字、文法、語用、社会レジスター、語形成、現代基礎語彙を一つに統合する
個別分野の詳細は各専門Docを参照するが、基本方針・固定事項・現在の到達点は本書を優先して解釈する


旧正本は初期設計段階の内容であり、動詞体系・証拠性・後置詞・複文・態・モダリティ・レジスター・500語辞書の成立前だったため、本版で全面更新する


## 1. プロジェクトの目的


架空世界で自然に成立し、長い歴史の中で変化してきた言語を構築する


単なる日本語・英語の単語置換ではなく、
祖語
前古典語
古典語
中世諸方言
近世標準語
現代標準語
という歴史的層を持つ


言語の独自性は奇抜な語形そのものではなく、
何を文法上区別するか
何を区別しなくてよいと考えるか
どの区別が社会史の中で文法化したか
に置く

## 3. 社会史上の原型


祖先社会は小規模共同体が広域に点在し、情報が人から人へ移動する社会だったと設定する


そのため
「何を知っているか」
だけでなく
「どうやって知ったか」
が交易・裁定・宗教・戦争・共同体運営で重要だった


この社会的圧力から、
見る
聞く
痕跡を追う
受け取る
未決のままにする
といった一般動詞が発話末へ集まり、証拠性標識へ文法化した


象徴的伝承として
「三つの証言の争い」
を置く


三人が同じ人物を犯人として指したが、
一人は直接見た
一人は人づてに聞いた
一人は痕跡から推論した
という違いが問題になったという法・教育上の物語


これは一事件が文法を生んだという設定ではなく、
何世代にもわたる法・交易・宗教実務を象徴する後世の典型譚である


## 4. 行為と人物の分離


小規模共同体では、
一度の問題行為を理由に有技能者を永久排除すると共同体自体が弱くなる


そのため文化的には
人物全体を一語で断罪すること
より
何をしたか
なぜ起きたか
意図はあったか
誰が結果責任を負うか
を分けて扱う傾向が発達した


この思想は現代話者が毎回意識する哲学ではなく、
長期の語用・法慣行が文法として残ったものとする
