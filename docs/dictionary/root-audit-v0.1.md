# Velka基礎語根監査 v0.1


### 位置づけ
現代語基礎辞書 v2.1 の913登録行を、語源注記と語形成に基づいて全件再分類し、ユニーク語形も別に数える
目的は「見出し語数」と「実際に独立して覚える必要がある語根数」を分離すること


## 1. 結論


現代語基礎辞書 v2.1
登録見出し行 913
ユニーク語形 911


歴史的な固有語根
128語
ユニーク語形の14.1%


借用され、現代語では分解不能な語幹
31語
ユニーク語形の3.4%


後代成立だが現在は分解不能として扱う確度粒子
3語
di / yo / pe
ユニーク語形の0.3%


したがって
共時的に「丸ごと覚える独立暗記単位」
128 + 31 + 3 = 162


残り
749ユニーク見出し
ユニーク語形の82.2%
は、原則として既存語根・既存語から透明に作られた派生語・複合語・語彙化形

## 3. 学習上の独立暗記単位


固有語根 128
借用語幹 31

この162を覚えれば911ユニーク語形が全部自動的に分かる、という意味ではない

## 14. 913と911の差


辞書内には同じ語形を後代に語義再固定した再掲が2件ある


navas
初出：目撃記録・直接証言
再掲：報道・司法での「目撃証言」義を再固定


suran
初出：使者・伝令・報告を届ける者
再掲：記者・報告者義を現代語として再固定


したがって
登録見出し行は913
ユニークな語形は911


今後、語彙規模を言う場合は「登録行」と「ユニーク語形」を分けて扱う


語根128、独立暗記単位162という数には、この重複は影響しない
