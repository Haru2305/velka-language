# 現代語基礎辞書 v2.1


### 位置づけ
現代標準語の基礎辞書 v2.1
v0.1の228見出し語をそのまま継承し、会話監査で実必要性が確認された22語を正式統合
v2.0までの907語を継承し、統計・疫学・機械学習の横断監査で必要性が確認された6語を正式統合して、合計913見出し語とする


### 本版の目的
日常会話から法律・契約・科学論文・研究データまで、現代社会の主要文書を短文から専門文まで連続して書ける語彙基盤を作ること
すべてを祖語から作らず、後代複合・意味拡張・借用語を混在させる


### 凡例
P＝祖語直系
P+＝本版で祖語候補として正式統合する古層語
C＝古典期までに成立した複合・派生
M＝中世成立
N＝近世〜現代成立
L＝借用
N-I〜N-V＝名詞クラス
V＝動詞
SV＝状態述語
PRON＝代名詞
PART＝粒子
